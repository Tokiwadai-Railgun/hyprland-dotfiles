# Requirements
This config uses the following tools : 
- Terminal : Kitty or Alacritty (smooth-cursor fork)
- Wallpaper : Hyprpaper
- RiverBar : Waybar
- lock screen : Hyprlock
- DE: Hyprland
- App Launcher : Fuzzel
- Idle Managment : HyprIdle
